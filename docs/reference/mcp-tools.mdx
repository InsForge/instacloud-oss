---
title: "MCP tools"
description: "The insta_* tools the hosted MCP server exposes, grouped by area."
---

The InstaCloud MCP server at `https://mcp.instacloud.com/mcp` (streamable HTTP) exposes the tools below. Authenticate with OAuth or an `insta_` API token; register it with `insta config install-mcp` or as part of [`insta agent setup`](/agents/setup).

<Note>
The CLI's linked directory does not carry over: project-scoped tools take an explicit `projectId`, and branch-scoped tools take `branch` as well. Agents discover project IDs with `insta_org_list` → `insta_project_list`. The set below grows regularly; the server's own tool listing is always current.
</Note>

## Identity and orgs

| Tool | What it does |
| --- | --- |
| `insta_whoami` | Return the authenticated identity and how the token was verified |
| `insta_org_list` | List the caller's organizations with their role |
| `insta_org_create` | Create a new organization |

## Projects

| Tool | What it does |
| --- | --- |
| `insta_project_list` | List projects in an org |
| `insta_project_create` | Create an empty project (add services afterwards) |
| `insta_project_get` | Get one project: services, branches, status |
| `insta_project_delete` | Tear down all of a project's resources |

## Branches

| Tool | What it does |
| --- | --- |
| `insta_branch_create` | Create an isolated environment from the project's current services |
| `insta_branch_list` | List a project's branches |
| `insta_branch_merge` | Structurally merge services from one branch into another (no data) |
| `insta_branch_delete` | Tear down a branch by name |

## Services

| Tool | What it does |
| --- | --- |
| `insta_service_add` | Provision a service (`postgres`/`storage`/`compute`/`redis`/`mysql`/`mongodb`) |
| `insta_service_list` | List a project's services, optionally per branch |
| `insta_service_remove` | Remove a service by type and name |
| `insta_service_access` | Make a service public or private |
| `insta_service_scale` | Set a compute service's machine count (paid plans) |
| `insta_service_upgrade` | Raise a compute or Postgres spec (up-only, paid plans) |

## Deploys and compute

| Tool | What it does |
| --- | --- |
| `insta_deploy` | Deploy a prebuilt container image to a compute service |
| `insta_compute_control` | Start, stop, suspend, or restart compute |
| `insta_compute_status` | A compute service's desired versus actual state |
| `insta_compute_exec` | Run a single command on a compute service and return the result |

## Secrets

| Tool | What it does |
| --- | --- |
| `insta_secrets_list` | Secret key names, grouped by branch and service (names only) |
| `insta_secrets_set` | Set a user-defined secret, project-wide or branch-scoped |
| `insta_secrets_unset` | Remove a user-defined secret |
| `insta_secret_sources` | List provider credential sources available for binding |
| `insta_secret_bindings` | List a compute service's provider credential bindings |
| `insta_secret_bind` | Bind a provider credential into a compute env var |
| `insta_secret_unbind` | Remove a provider credential binding |

## Storage

| Tool | What it does |
| --- | --- |
| `insta_storage_list` | One page of a bucket's objects, with cursor pagination |
| `insta_storage_download_url` | Presign a short-lived download URL for one object |
| `insta_storage_delete` | Permanently delete one object |

## Domains

| Tool | What it does |
| --- | --- |
| `insta_domain_set` | Attach a custom domain to a branch's compute service |
| `insta_domain_check` | Re-check a domain's certificate status and required DNS records |
| `insta_domain_remove` | Detach a custom domain |

## Observability

| Tool | What it does |
| --- | --- |
| `insta_metrics` | Metrics for a component |
| `insta_logs` | Runtime logs for a component |
| `insta_deploy_events` | Machine lifecycle events (the deploy log) |
| `insta_events` | The project's audit and agent-event timeline |
| `insta_manifest` | Agent-legible environment view: branches, services, bound secret names, URLs |

## Billing and usage

| Tool | What it does |
| --- | --- |
| `insta_usage` | Usage across billing dimensions with cost |
| `insta_billing_summary` | Current-cycle summary: tier, included credit, used, overage |
| `insta_billing_checkout` | Start a checkout to subscribe to a paid tier |
| `insta_billing_portal` | Open the billing portal session |

## Templates and feedback

| Tool | What it does |
| --- | --- |
| `insta_template_search` | Search the template catalog |
| `insta_template_deploy` | Deploy a catalog template or raw manifest into a branch |
| `insta_template_deployment_status` | Poll an async template deployment |
| `insta_feedback` | Report an InstaCloud-side bug, missing feature, or friction |
