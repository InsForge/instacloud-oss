# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull
requests.

Instead, email [info@insforge.dev](mailto:info@insforge.dev) with:

- a description of the issue and the impact you believe it has,
- the steps or a proof of concept to reproduce it,
- the version or commit you tested (`insta --version`, or the daemon image tag), and
- any relevant logs or configuration, with secrets removed.

We will acknowledge your report, keep you updated on the fix, and credit you when a fix ships if you
would like. Please give us a reasonable chance to release a fix before any public disclosure.

## Supported versions

Fixes land on `main` and in the newest release. Self-hosted operators should track the latest
release; re-running `install.sh` upgrades a box in place.
